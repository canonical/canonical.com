What does MAAS do?

{%- endif -%} {%- if slot == 'description' -%}

MAAS creates one control plane for heterogeneous infrastructure. Modern data centers rarely contain identical machines. Servers differ across vendors, generations, architectures, and configurations. MAAS provides a common management layer across this heterogeneous infrastructure. It discovers machines and maintains an accurate inventory of their hardware, configuration, state, and availability, giving operators a consistent view of the physical resources they manage.

{%- endif -%} {%- if slot == 'list_item_title_1' -%}

Discover physical machines

{%- endif -%} {%- if slot == 'list_item_description_1' -%}

MAAS can automatically detect and register new machines, bringing hardware from different vendors and architectures under the same control plane.

{%- endif -%} {%- if slot == 'list_item_title_2' -%}

Inventory hardware capabilities

{%- endif -%} {%- if slot == 'list_item_description_2' -%}

MAAS records CPU, architecture, memory, disks, network interfaces, GPUs, DPUs, and other attached hardware.

{%- endif -%} {%- if slot == 'list_item_title_3' -%}

Track configuration and state

{%- endif -%} {%- if slot == 'list_item_description_3' -%}

MAAS keeps track of network configuration, power management, lifecycle state, and the machine availability.

{%- endif -%} {%- if slot == 'list_item_title_4' -%}

Create a common infrastructure model

{%- endif -%} {%- if slot == 'list_item_description_4' -%}

Different machines are represented and managed consistently, providing a single source of truth for the whole bare metal state.

Bare metal cloud

{%- endif -%} {%- if slot == 'list_item_description_1' -%}

MAAS can turn a fleet of physical servers into an on-demand bare metal cloud, where machines are allocated and repurposed as needed, instead of being tied permanently to a specific role. This offers a cloud-like way to consume physical infrastructure, while keeping direct access to the hardware.

Learn how to build and run an effective bare metal cloud ›
{%- endif -%} {%- if slot == 'list_item_title_2' -%}

Bare metal Kubernetes

{%- endif -%} {%- if slot == 'list_item_description_2' -%}

Kubernetes can run on MAAS-managed servers, giving workloads direct access to the underlying hardware. This can improve performance and predictability for workloads that benefit from direct hardware access, including High Performance Computing (HPC) and other performance-sensitive environments.

Learn more about bare metal Kubernetes in our whitepaper ›
{%- endif -%} {%- if slot == 'list_item_title_3' -%}

Private cloud

{%- endif -%} {%- if slot == 'list_item_description_3' -%}

MAAS can provide the physical infrastructure for MicroCloud or OpenStack, taking care of bare metal provisioning while the cloud platform manages virtual machines, networking, storage, and higher-level cloud services.

How MAAS supports private cloud operations ›
{%- endif -%} {%- if slot == 'list_item_title_4' -%}

AI Factories

{%- endif -%} {%- if slot == 'list_item_description_4' -%}

MAAS provides the bare metal foundation for AI infrastructure, where direct access to GPUs, high-speed networking and other specialized hardware is critical. By automating provisioning, hardware validation and recovery, MAAS helps keep expensive compute resources available and ready for AI workloads.

Learn more about architecting bare metal for AI Factories ›

Sovereign cloud

{%- endif -%} {%- if slot == 'list_item_description_5' -%}

Sovereign cloud strategies are increasingly important for organizations that need greater control over where their data and infrastructure run and how they are operated. MAAS helps organizations operate the physical layer on their own terms instead of relying on proprietary tools or manual processes.
